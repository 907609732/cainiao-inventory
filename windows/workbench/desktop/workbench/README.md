# 云仓工作台接口

本目录保留 Windows 云仓与现有工作台对接所需的请求身份、操作清单、库存及月销量适配和受控业务接口。独立云仓使用 `desktop/main.mjs` 启动，安装和开发入口见 [Windows 说明](../../../README.md)，当前软件架构见[仓库架构说明](../../../../docs/architecture.md)。

`desktop/modules/cloud-control.mjs` 提供云仓受控接口，`warehouse-agent.mjs` 提供采集、校验、导入及投递能力，`warehouse-adapter.mjs` 提供工作台页面与数据适配。签名请求、原件归属、复核和防重复写入继续按源码契约执行。

网关相关文件是工作台集成支持代码，独立安装器并不将它们作为额外服务启动。旧的独立 ERP 客户端和客户端迁移目录已清理，云仓签到 / 考勤已移除。不要套用旧工作台启动命令或把网关测试视为正式环境验收。
