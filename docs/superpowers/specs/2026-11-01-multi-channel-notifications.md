# 多渠道通知设计

用户已确认：支持多个渠道同时发送。设置区改为通知渠道，保留钉钉现有配置，新增飞书应用机器人、企业微信群机器人、SMTP 邮箱和 Telegram。各渠道独立启用，全部已启用渠道接收同一份报告；默认仅保留既有钉钉启用状态。

复用 MIT 许可 push-all-in-one 4.6.0，匹配当前 Node/Electron 运行时；不自写平台 HTTP/SMTP 协议。密码、Token、Webhook 密钥沿用 Windows safeStorage。配置保存不发送消息。新增渠道默认关闭；不读取或修改已安装软件及正式账本。

发送按渠道返回 accepted/failed/unknown，部分失败不能伪装全部成功。网络结果不明不自动重试，避免重复通知。库存同步和手动沿用已校验库存均接入统一发送。已有月报发送路径保留去重并扩展渠道维度。测试全部使用模拟提供商/临时账本，不发送到真实收件人。
